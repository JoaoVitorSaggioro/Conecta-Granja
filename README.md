Conecta Granja

Sistema de gerenciamento de granjas desenvolvido como projeto de TCC.

Tecnologias utilizadas
Frontend
React
Tailwind CSS
Vite
JavaScript
Backend
Node.js
Express
Sequelize
SQLite
Estrutura do projeto
Conecta-Granja/
├── Backend/
└── Frontend/
Sobre o projeto

O Conecta Granja tem como objetivo auxiliar no gerenciamento de informações relacionadas à produção e administração de granjas, centralizando dados e operações em uma aplicação web.

Execução local
Backend
cd Backend
npm install
npm start

O backend será executado em:

http://localhost:3000
Frontend
cd Frontend
npm install
npm run dev

O frontend será executado em:

http://localhost:5173
